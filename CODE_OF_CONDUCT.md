# Code of Conduct

## Our pledge

We as members, contributors, and maintainers pledge to make participation
in this project a harassment-free experience for everyone, regardless of
age, body size, visible or invisible disability, ethnicity, sex
characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance,
race, religion, or sexual identity and orientation.

## Our standards

Examples of behavior that contributes to a positive environment:

- Being respectful of differing opinions, viewpoints, and experiences.
- Giving and gracefully accepting constructive feedback.
- Focusing on what's best for the project and the people using it.

Examples of unacceptable behavior:

- Harassment, insults, or derogatory comments, public or private.
- Publishing others' private information without explicit permission.
- Any other conduct that could reasonably be considered inappropriate in
  a professional setting.

## Scope

This applies within all project spaces (issues, pull requests,
discussions, code review) and when representing the project in public
spaces.

## Enforcement

Report unacceptable behavior privately through this repository's
**Security** tab → **Advisories** → **Report a vulnerability** — the
same private channel [SECURITY.md](.github/SECURITY.md) uses for
vulnerability reports, since this repository has no separate public
contact address. Include what happened, when, and (if applicable) links
to the relevant issue/PR/comment.

All reports will be reviewed and investigated, and a response will
always respect the reporter's privacy. Maintainers who don't follow or
enforce this Code of Conduct in good faith may face repercussions as
determined by other members of the project's leadership.
