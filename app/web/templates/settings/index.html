Dashboard trends

A background job records one daily snapshot of fleet-wide counts (online/offline machines, pending updates, ...) for the trend chart(s) on the Dashboard. This only controls how long those snapshots are kept — it doesn't affect the live counts themselves.

Leave empty to keep every snapshot forever. Defaults to 90 days.

Syslog forwarding

Live-mirrors every audit log entry to an external syslog server (e.g. a SIEM) as it's written — RFC 5424 formatted, best-effort: a delivery failure here is only ever logged, never blocks the action being audited. The database entry (exportable above) is always the real record; this is just a copy sent elsewhere.

Token limits

Global ceilings on total tokens (input + output, all providers together) spent by the AI assistant in a rolling window — the last 24 hours, 7 days, and 30 days respectively, not calendar days/weeks/months. A limit that is already reached blocks the next chat turn before any provider call is made. Leave empty for no limit.
