System updates

Always runs apt-get update, then the selected upgrade strategy, then autoremove and autoclean (the cleanup steps run regardless of whether the upgrade step succeeded) — and, if installed, flatpak update and snap refresh too. Requires root for apt — either the configured user is root, or has passwordless sudo for apt-get (and, recommended, flatpak/ snap too). See the wiki page "Managed Machine Requirements" for a sudoers example.
