Import machine & group configuration

Paste JSON exported from Machines ("Export config (JSON)"). This creates real machines and groups directly — it is not the pending-review queue bulk import uses, so it's meant for restoring/migrating already-known configuration, not discovering unknown hosts.

This is a structural export/import, not a credentials backup: it never contains (or restores) a machine's password/key material or its pinned SSH host-key fingerprint. A machine originally using password authentication is imported with "SSH key" instead (there's nothing to re-import) — its name is called out below so you can revisit its credentials. Every imported machine starts with no pinned host key, exactly like a freshly hand-added one — use "Discover key fingerprint" and confirm it before anything connects to it.

A machine whose name already exists is skipped, not overwritten — this never changes an existing machine's connection details.
